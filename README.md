# Pharis — سيدي بلعباس تغطية محلية كاملة (جاهز للرفع)

## الملفات الأساسية للرفع
1. `index.html` — فيه **224** صيدلية SBA مدمجة + وهران/الجزائر السابقة + تحسين Overpass + زر التحديث
2. `service-worker.js` — إصدار `pharis-v64-sba-full` (ارفعه مع index.html)

## مرجع (اختياري)
- `sba.json` / `sba_city.json` / `sba.csv`

## التثبيت
1. استبدل `index.html` و `service-worker.js` في مشروعك
2. ارفع التعديل
3. عند المستخدم: يظهر زر «تحديث جديد» بعد ثوانٍ

## ملاحظة
بعض الإحداثيات تقريبية داخل الحي — يمكن تصحيحها لاحقاً من الخريطة.
