# بيانات صيدليات محلية إضافية — Pharis

## المحتويات
- `alger.json` — صيدليات ولاية الجزائر (بياناتك الحالية + مصادر عامة)
- `oran.json` — صيدليات وهران (بياناتك + Evexia + Éternel)
- `sba.json` — صيدليات سيدي بلعباس (بياناتك + Evexia)

## ملاحظات مهمة
1. بعض الإحداثيات **تقريبية** (حقل `coordsApprox: true`) — يُفضّل تصحيحها من Google Maps.
2. الساعات الافتراضية 8–21 عند غياب البيانات.
3. الهواتف مأخوذة من قوائم شركاء عامة (Evexia / Éternel) وقد تتغير.
4. ادمج مع ملفاتك الحالية بحذر (تجنب التكرار بالاسم + الإحداثيات).

## طريقة الدمج
استبدل أو ادمج الملفات في مستودع Pharis:
- `alger.json` / `oran.json` / `sba.json`
أو انسخ العناصر الجديدة إلى المصفوفات داخل `index.html`.
