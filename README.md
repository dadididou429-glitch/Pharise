# Pharis — تعزيز البيانات المحلية (الجزائر · وهران · سيدي بلعباس)

## ماذا يوجد في هذا الأرشيف؟
- `index.html` — نسخة جاهزة مع:
  - بيانات محلية موسّعة مدمجة
  - أولوية للمحلي على OSM عند نفس الموقع
  - نطاق محلي أوسع عند تحديد الموقع (55 كم)
  - تحسين Overpass السابق
  - **زر التحديث يعمل كالعادة** (يحدّث OSM دون حذف المحلي)

- `alger.json` / `oran.json` / `sba.json` — نفس البيانات منفصلة للمرجع

## الأعداد
| الولاية | العدد تقريباً |
|---------|----------------|
| سيدي بلعباس | 175 |
| وهران | 135 |
| الجزائر | 83 |

## التثبيت
1. انسخ `index.html` إلى جذر مشروع Pharis (استبدل الملف الحالي).
2. ارفع التعديل (GitHub Pages / Glitch / Firebase).
3. عند المستخدم: زر التحديث السريع يعمل كما هو — يجلب OSM إضافي ويُبقي المحلي.

## ملاحظات
- بعض الإحداثيات المضافة تقريبية؛ يُفضّل تصحيحها لاحقاً من الخريطة.
- البيانات المحلية تظهر أولاً داخل الولايات الثلاث.
- خارج هذه الولايات يبقى الاعتماد على Overpass حسب الموقع.

## إصلاح زر التحديث (v63)
- تم رفع إصدار الـ Service Worker: `pharis-v63-local-boost`
- الزر يظهر عند اكتشاف تحديث (لا إعادة تحميل تلقائية)
- ارفع **معاً**: `index.html` + `service-worker.js`
- بعد الرفع: افتح التطبيق وانتظر بضع ثوانٍ — يظهر «🔄 تحديث جديد»
