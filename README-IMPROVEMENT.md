# Pharis — تحسين جلب الصيدليات (Overpass)

## ماذا تغيّر؟
تعديل **آمن ومحدود** داخل `index.html` فقط على منطق جلب OpenStreetMap:

1. نصف قطر ابتدائي أكبر: 15 كم (بدلاً من 12)
2. توسيع تلقائي: 15 → 25 → 40 كم إذا كانت النتائج أقل من 8
3. وسوم إضافية: shop=pharmacy و dispensing=yes و relation
4. timeout أطول (18 ثانية للطلب + 20 ثانية للشبكة)
5. endpoint إضافي لـ Overpass لتقليل الفشل

## ما لم يتغير
- البيانات المحلية (SBA / Oran / Alger)
- الواجهة والتصميم
- Firebase / المناوبات / التقييمات / الإضافات
- أسماء الدوال الأساسية (متوافقة مع الكود القديم)

## طريقة الاستخدام
استبدل ملف `index.html` في مستودعك بهذا الملف ثم ارفع (GitHub Pages / Glitch / Firebase Hosting).

## تراجع سريع
أعد `index.html` من النسخة السابقة في Git إذا احتجت.
