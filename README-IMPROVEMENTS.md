# Pharis — التحسينات المطبقة (v9)

## ما تم تحسينه

### 1. تحديد الموقع (أسرع + أدق)
- كاش للموقع السابق (يظهر المحتوى فورًا خلال 30 دقيقة)
- محاولة أولى بدقة عالية (timeout 5 ثوانٍ)
- fallback تلقائي لدقة منخفضة إذا فشلت الأولى
- عرض احترافي: **المدينة، الدولة** (مثل: سيدي بلعباس، الجزائر)

### 2. أيقونة الأعلى
- تم استبدال أيقونة المشاركة بأيقونة التحميل (Download)
- عند الضغط تنسخ كود Downloader: `5040717`

### 3. تحديث سريع على GitHub Pages
- Service Worker جديد: `pharis-v9`
- `skipWaiting` فور التثبيت
- حذف الكاش القديم فور التفعيل
- فحص التحديثات كل 20 ثانية + عند العودة للتطبيق
- `index.html` و `manifest` يُجلبان من الشبكة أولًا (Network First)

## طريقة الرفع على GitHub

1. فك الضغط عن الملف
2. انسخ كل الملفات إلى مستودعك `Pharise`
3. ارفع (commit + push) إلى الفرع `main`
4. انتظر دقيقة ثم افتح الموقع مع **تحديث قوي**:
   - Android/Chrome: امسح بيانات الموقع أو افتح في نافذة خاصة
   - أو اضغط زر «تحديث الآن» إذا ظهر البانر

## ملاحظة مهمة لتسريع التحديث دائمًا

عند أي تعديل مستقبلي غيّر رقم الكاش في `service-worker.js`:

```js
const CACHE_NAME = "pharis-v10"; // زد الرقم
```

هذا يجبر كل الأجهزة على تحميل النسخة الجديدة فورًا.
